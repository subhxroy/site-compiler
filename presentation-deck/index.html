08 • Core Technical Innovation DOM Sanitization

Algorithmic Watermark & Artifact Pruning Engine

Targeted heuristic pruning removes platform branding and builder tracking without disrupting layout geometry.

The Technical Challenge

Builder watermarks are dynamically injected via client runtime scripts or fixed overlays. Naively removing parent containers collapses CSS grids and breaks layouts.

3-Tier Heuristic Pruning Strategy
01. Pattern Selectors: Targets builder attributes ([data-framer-watermark]).
02. Geometric Anchors: Detects fixed viewport overlays with external vendor links.
03. Layout Safety Guards: Preserves legitimate navigation, headers, and user CTAs.
Result: 100% clean DOM without forced platform branding
